📋 MISSION BRIEFING

🎮 How to Play:

  • Shooter Phase: Move your ship with mouse/touch, click/tap to shoot aliens
  • Boss Fights: Giant motherships appear! Solve programming puzzles to defeat them
  • Planet Conquest: Win levels to conquer planets, lose and retreat to previous ones
  • Final Stand: If you lose Earth, humanity becomes slaves forever!

💡 Programming Concepts:

Don't worry if you're new to programming! Each level teaches you concepts through gameplay:

  • Sequencing: Steps in order (Level 1)
  • Loops: Repeating actions (Level 2)
  • Conditions: If/Else decisions (Level 3)
  • Variables: Storing values (Level 4)
  • Functions: Reusable code blocks (Level 5)
  • Debugging: Finding errors (Level 6)
  • Mixed Challenge: Use everything! (Level 7)
